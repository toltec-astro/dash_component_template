# Type Stubs for dash_component_template

This directory contains Python type stub files (`.pyi`) that provide IDE autocomplete and type checking for dynamically created ComponentTemplate classes.

## Overview

The `dash_component_template` library dynamically generates `ComponentTemplate` subclasses at runtime for Dash components (like `html.Div`, `dcc.Dropdown`, etc.). While these classes work perfectly at runtime, IDEs and type checkers cannot see them during static analysis because they don't exist in source code.

**Type stubs solve this problem** by providing static type information that mirrors the runtime behavior.

## What's Included

- **`html.pyi`**: Type stubs for all `dash.html` components (125 components)
  - `ComponentTemplateDiv`, `ComponentTemplateButton`, `ComponentTemplateInput`, etc.

- **`dcc.pyi`**: Type stubs for all `dash.dcc` components (25 components)
  - `ComponentTemplateDropdown`, `ComponentTemplateGraph`, `ComponentTemplateSlider`, etc.

## Benefits

### ✅ Full IDE Autocomplete

```python
from dash import html
from dash_component_template import make_component_template_cls

DivTemplate = make_component_template_cls(html.Div)

# IDE autocompletes all properties in __init__
div = DivTemplate(
    className="...",     # ✅ Autocomplete works!
    style={...},         # ✅ Autocomplete works!
    children_=[...],     # ✅ Autocomplete works!
)

# IDE autocompletes all properties as attributes
div.className = "box"  # ✅ Autocomplete works!
div.style = {...}      # ✅ Autocomplete works!
```

### ✅ Type Checking

```python
# Type checkers can validate your code
div = DivTemplate(className="valid")      # ✅ OK
div = DivTemplate(className=123)          # ❌ Type error!
div = DivTemplate(nonexistent="value")    # ❌ Unknown parameter!
```

### ✅ Better Documentation

IDEs can show you:
- What properties are available
- What types they accept
- Docstrings and hints

## How It Works

1. **Runtime**: `make_component_template_cls()` dynamically creates `ComponentTemplateDiv` class
2. **Static Analysis**: IDE/type checker reads `html.pyi` stub file
3. **Result**: IDE sees all properties and provides autocomplete

## Regenerating Stubs

If you update Dash or add new component libraries, regenerate the stubs:

```bash
# Regenerate all common stubs (html, dcc)
python -m dash_component_template.stub_generator

# Generate stubs for a specific namespace
python -m dash_component_template.stub_generator dash.bootstrap_components
```

## Technical Details

### File Structure

```
dash_component_template/
├── stubs/
│   ├── __init__.py       # Documentation
│   ├── html.pyi          # 125 HTML components
│   └── dcc.pyi           # 25 DCC components
└── py.typed              # PEP 561 marker
```

### PEP 561 Compliance

This package is PEP 561 compliant:
- ✅ Contains `py.typed` marker file
- ✅ Stubs are inline with package (not separate)
- ✅ Type checkers automatically discover stubs

### Stub Generation

Stubs are generated by introspecting Dash component `__init__` signatures:

```python
from dash import html
from dash_component_template.stub_generator import generate_stub_for_component

stub_content = generate_stub_for_component(html.Div)
# Creates .pyi file with all properties and __init__ signature
```

### Type Simplification

Complex Dash type annotations are simplified to `Any` for maintainability:
- ✅ Simple types: `str`, `int`, `bool`, `dict`, `list`
- ✅ Unions: `str | int | None`
- ❌ Complex: `Sequence[str | int | Component]` → `Any`

This provides autocomplete without overwhelming users with complex types.

## Examples

### Basic Usage

```python
from dash import html
from dash_component_template import make_component_template_cls

# Create typed template class
DivTemplate = make_component_template_cls(html.Div)

# Full autocomplete in __init__
container = DivTemplate(
    className="container",
    style={"padding": "20px"},
)

# Full autocomplete as attributes
container.className = "container-fluid"
container.style = {"margin": "10px"}
```

### With Type Checking

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    # Import stub types for type checking only
    from dash_component_template.stubs.html import ComponentTemplateDiv

def create_layout() -> ComponentTemplateDiv:
    DivTemplate = make_component_template_cls(html.Div)
    return DivTemplate(className="app-layout")
```

### Tree Building

```python
from dash import html

DivTemplate = make_component_template_cls(html.Div)
ButtonTemplate = make_component_template_cls(html.Button)

# Autocomplete works for all components
container = DivTemplate(className="container")
button = ButtonTemplate(
    children_="Click Me",
    className="btn btn-primary",
    parent=container,
)
```

## Limitations

1. **Dynamic Properties**: If you add custom properties at runtime, they won't appear in autocomplete
2. **Type Accuracy**: Complex Dash types are simplified to `Any`
3. **Completeness**: Only generated for common namespaces (html, dcc)
